# Per-Section Research Guide

Companion to `INSTRUCTIONS.md`. Research one section at a time, write it, save, then research the next. Query budgets below are ceilings, not targets — if one Wikipedia page answers three sections, use it for all three. Total ceiling per language: ~20 searches.

## General sources

Wikipedia (structure, history, statistics), Ethnologue/Glottolog (speaker counts, classification), Unicode CLDR & ISO 639 (locale codes), Omniglot (scripts). For conlangs: creator publications, fandom wikis (Memory Alpha, Tolkien Gateway), Duolingo/learning-platform stats. Prefer the CSV values in `data/` over anything you find — they are authoritative for name, type, speakers, and parent language.

## written (1–2 searches)

Locale/ISO code (verify against ISO 639 / CLDR; conlangs may have ISO 639-3 codes like `tlh`), etymology of the language's name, literacy/reader estimates, native script(s). Typeface table: fonts that actually render the script on each OS — Noto family covers most; dead scripts need specific Unicode fonts (Noto Sans Cuneiform, Noto Sans Egyptian Hieroglyphs). `Google translatable` — check Google Translate's supported-language list. `Suno readable` — check whether Suno can render lyrics in it; if unverifiable, `no`.

## spoken (1–2 searches)

Speaker count comes from the CSV — don't re-research it. Search for: dialect/register breakdown (3–6 rows), where spoken. `tempo` and `literacy` per dialect are impressionistic calls grounded in what you read — pick fast/mid/slow and high/mid/low and move on; don't burn queries on them.

## signed (0–1 searches)

Only living national languages usually have one. One search: "<country> sign language" — name, signer count, governing bodies. Dead/constructed: skip the search, write `none attested`.

## eras (1 search)

"History of <language>" — extract 4–8 named periods. You may name eras in-universe style (en-US uses war eras) as long as the `firstseen` dates are real. Holocene dates.

## intro + sections nav (0 searches)

Written from what you already learned. Intro: one paragraph, satirical framing, real substance underneath. Nav table: mechanical substitution of the filename.

## ambassadors (1 search per top-5 table, 12 total)

The expensive section — treat each top-5 table as its own research+write step. Pick categories per the adaptation rules in INSTRUCTIONS.md *before* searching, then one targeted query each: "largest cities <country> population", "most translated Esperanto books", "most cited Latin texts", etc. Each table: 5 rows, name + at least one real stat (population, count, year, length). If a query can't produce five sourced rows, swap the category rather than padding with guesses. Ranked lists ("top-5 films") can follow a recognized ranking (IMDb, box office) — pick one and be internally consistent.

## origins (2–3 searches)

"History of <language> timeline", plus follow-ups for gaps. 8–20 events, newest first, Holocene dates, each written as a one-sentence story with (age) annotations for people and institutions. Highlight milestones with ==marks==: first writing (==written-form==), signed form (==signed-form==), standardization, decipherment, death — whatever the language's real turning points are. Anchor events to real people, dates, and publications; the wit goes in the phrasing.
